# AquaAlert
AquaAlert is a ruggedized, localized IoT water management system designed to provide zero-recurring-cost automation for rural water infrastructure. By leveraging LoRa (Long Range) communication and edge computing, the system operates entirely offline, independent of cellular networks or internet connectivity.
🚀 Key Features
LoRa Star Network: Eliminates the need for 50ft+ sensor cables, preventing lightning-induced hardware failure.

Edge Intelligence: Raspberry Pi-based local web dashboard accessible via a private Wi-Fi access point.

Industrial Retrofit: Retrofits existing manual motor starters, reducing infrastructure costs by 30%.

Zero-Recurring-Cost: Operates on solar harvesting with no ongoing subscription or data fees.

🛠 Tech Stack
Hardware: ESP8266 (NodeMCU), SX1278 LoRa Modules, JSN-SR04T Waterproof Ultrasonic Sensor.

Backend: Python (Flask), SQLite for telemetry logging.

Frontend: Tailwind CSS, Chart.js for real-time visualization.

Firmware: C++ (Arduino/PlatformIO framework).
